# Agent 搭建与导入执行指南

适用于任意具备文件和命令能力的编程 Agent，不要求使用特定模型。先读根目录 AGENTS.md 和 README.md。

1. **获取项目**：clone README 中的仓库，检查 Node >=20.19、npm 和现有文件。不要覆盖已有工作目录。运行 npm ci。
2. **本地跑通**：npm run install:local；npm run serve:mock。实际打开页面，核对公式、图片、三分区、笔记、每日完成、目标与草稿板。没有题目材料时，到这里已经可以体验。
3. **收集材料**：询问用户尚未提供的文件路径与范围。按 IMPORTING.md 先制作少量代表题，保留来源定位并核对；批量整理完整快照，疑点留在私有清单。不要要求用户预先拥有别人整理好的专用 zip。
4. **导入**：npm run import:bank -- <bank.json> 只读预检；在授权导入范围内追加 --apply。setup/build 后重启预览，实际验收。保留旧题 ID、学习记录、退役题及图片。
5. **云端准备**：如果用户需要云同步，集中列出仍缺少的环境 ID、地域、邮箱、UID、认证提供方、安全域名、函数权限和 PostgreSQL 状态。指导本地填写 .env，不索取聊天中的密钥。
6. **部署**：已有明确授权时继续；尚未授权时先完成本地可审阅结果。按照 DEPLOYMENT.md dry-run，再迁移数据库、部署函数和 public。不能擅自购买套餐或删除资源。
7. **验收与交接**：真实账号与第二个隔离浏览器验证同步，核对离线与升级。清楚标明仅完成模拟的项目。交付网址、题目数量/待核对数量、备份位置、常用维护命令与未验证项。

任何提交前检查暂存文件。题目材料、私有资源清单、题库历史、配置、数据库导出、学习记录和日志不能进入公开仓库。只提交源码、虚构测试素材、文档与许可证。
